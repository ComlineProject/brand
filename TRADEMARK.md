# Trademark & brand usage

The name **Comline** and the **Comline mark** (`logo/`, `favicon/`) are
trademarks of the Comline project. They are **not** covered by the open-source
licenses that apply to Comline's code — they are handled here instead.

This matters because Comline's code is copyleft: anyone may fork it. This
notice is what keeps a fork from presenting itself *as* Comline.

## You may, without asking

- Use the name and the mark to **refer to** the Comline project — in prose,
  documentation, articles, talks, comparisons, "works with Comline" / "built
  on Comline" statements, and links back to the project.
- Redistribute the mark **unmodified** alongside an unmodified distribution of
  Comline (e.g. in a README, a package page).
- Use `tokens.json` colour values freely.

## Please don't, without written permission

- Use "Comline" (or a confusingly similar name) as the name of **your** product,
  service, fork, company, or domain, or in a way that implies the project
  endorses or is affiliated with your work.
- Modify, recolour, redraw, or animate the mark, or use it as the primary
  identity of a different project.
- Register "Comline" or the mark as a trademark anywhere.

## Third-party marks

`third-party/` holds GitHub's and GitLab's marks — those are **their** assets
under **their** terms, included here only for "view on GitHub / GitLab" links.
Not ours to relicense.

## Contact

Open an issue on `ComlineProject/brand` for permission requests or questions.
